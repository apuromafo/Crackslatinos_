# Crackslatinos

Crackslatinos es una comunidad de más de 20 años de existencia. Ricardo Narvaja es quien ha hecho una serie de tutoriales para aprender de estas skills. En el 2026 se aprecia la página caída, así que también he dejado respaldado.

- Sitio original: https://ricardonarvaja.info/
- Limitación: GitHub no permite subir sobre 100 MB de forma directa, así que uso WinRAR para compresión. Ejercicios sueltos en ZIP con clave `a`.
